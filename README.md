# BASKET 3ON3

スマホとPCで遊べる、ブラウザ用の2.5D 3on3バスケットボールゲームです。

## Play

GitHub Pagesで公開する場合は、リポジトリの `Settings > Pages` から以下を選びます。

- Source: Deploy from a branch
- Branch: main
- Folder: /root

公開後は `https://ユーザー名.github.io/リポジトリ名/` で起動できます。

## Files needed for publishing

- `index.html`
- `basket3on3.html`
- `assets/ball/*.png`

PSDファイルは作業用なので公開には不要です。
